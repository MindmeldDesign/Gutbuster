# Gutbuster prototypes

Standalone HTML explorations made before (and alongside) the Next.js build. Each file opens directly in a browser, no build step. They are reference material, not part of the app, so nothing in `src/` imports them.

| File | What it is |
|---|---|
| `2026-09-07-floor-plan.html` | Information architecture: three ways to lay out the aisles (genre, theater, format) and the recommended hybrid with a facet rail |
| `2026-09-14-shelf-feedback-flow.html` | Six-step spec for the "customize your shelf" flow (skip a set, skip a team, tell us why, back room) |
| `2026-09-14-shelf-feedback-prototype.html` | Clickable mobile version of the shelf feedback flow |
| `2026-09-18-roadmap.html` | Three-track roadmap: Are.na prototype, content pipeline, official product |
| `2026-10-19-staff-picks-wireframe.html` | Low-fidelity interactive mobile wireframe: Staff Picks, Favorites, You, and the Form picker sheet |

Note on design direction: the Floor Plan uses the earlier neo-brutalist type (pixel display, IBM mono). The shelf feedback files and roadmap use the newer rental-store / pop-art system (Bowlby One, Space Grotesk, Courier Prime). The Staff Picks file is a grayscale wireframe on purpose.
